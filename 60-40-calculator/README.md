# คิดง่าย 60/40

เว็บคำนวณสัดส่วนร่วมจ่าย 60/40 แบบหน้าเดียว ใช้ได้ฟรีและไม่เก็บข้อมูล

## รูปแบบการคำนวณ

1. รู้จำนวนเงินรัฐบาล → คำนวณเงินประชาชนและยอดรวม
2. รู้จำนวนเงินประชาชน → คำนวณเงินรัฐบาลและยอดรวม
3. รู้ราคาสินค้า → แบ่งเป็นเงินรัฐบาล 60% และเงินประชาชน 40%

เว็บเป็นไฟล์สแตติกทั้งหมด เปิด `index.html` เพื่อใช้งานได้ทันที
